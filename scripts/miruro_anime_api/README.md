# Miruro capture

`api_client.ts` was generated by [reverse-api-engineer](https://github.com/kalil0321/reverse-api-engineer) from a Miruro browser capture (run `040832f2f158`). The app uses `src/lib/miruro-data.ts`, which reads the verified SvelteKit page data routes for catalog entries, episodes, HLS sources, and VTT subtitles. Miruro's standalone `/api/search/browse` request was blocked from this server, so the app reads `/search/__data.json` instead.

The generated file is retained as capture reference. Stream links are signed and must be fetched again when an episode is selected. Only direct HLS URLs are offered in the app player; embed scripts are not loaded.
